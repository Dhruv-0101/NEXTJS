Making User Profile Endpoint in Next.js

Learn how to create a secure GET /api/user profile endpoint that leverages getLoggedInUser() to return current user account details to the frontend.

⚙️

1. Profile Endpoint Architecture

👤 Profile Data Retrieval

When the React frontend mounts, components (e.g. Navigation Header or Account Settings) invoke fetch('/api/user').
The route handler verifies the active session cookie and returns the logged-in user object.

🔒 Zero-Trust Protection

No client parameters (e.g., ?userId=123) are trusted.
The endpoint extracts the user identity exclusively from the secure HTTP-Only session cookie via getLoggedInUser().

5. Poora Saar & Golden Master Rule (Hinglish)

💡 User Profile Endpoint Ka Poora Saar:

GET /api/user endpoint React frontend ko **Currently Logged-In User** ki details (Name, Email, Preferences) provide karta hai.

Security ka sabse bada rule: Client dwara bheji kisi bhi query ID par bharosa nahi karte! Handler direct getLoggedInUser() chalata hai jo authenticated cookie se user nikaalta hai. Agar user logged in nahi hai ➔ 401 Unauthorized chala jata hai!

🔥 Profile API Golden Pattern:
  • 1. No Trusted Client IDs 🚫 ➔ Never pass /api/user?id=123; extract identity solely from session cookie.
  • 2. Instanceof Guard 🛡️ ➔ Return 401 immediately if user instanceof Response.
  • 3. Clean JSON Response 📦 ➔ Return sanitized user object containing essential UI fields.
