1. Cookie Management in Next.js App Router

🍪 Async Cookie Store API

In Next.js 15+, cookies() is an asynchronous function.
Syntax: const cookieStore = await cookies();
Allows reading incoming HTTP request headers (cookieStore.get('userId')) and setting response headers (cookieStore.set()).

🛡️ Mandatory Security Flags

• httpOnly: true ➔ Blocks browser client JS (document.cookie) from reading the cookie. Eliminates XSS attacks!
• maxAge: seconds ➔ Specifies exact lifetime before the browser auto-deletes the cookie.

5. Poora Saar & Golden Master Rule (Hinglish)

💡 Cookies In Next.js Ka Poora Saar:

Next.js Server Side par Cookies handle karne ke liye cookies() helper next/headers se import karte hain.

Next.js 15 me cookies() async hota hai (const cookieStore = await cookies();). Jab aap cookie set karte ho, httpOnly: true flag lagana FARZ hai taaki client-side JavaScript (hacker ka XSS script) us cookie ko read/chura na sake!

🔥 3 Cookie Rules to Master:
  • 1. Always Await ⏳ ➔ const cookieStore = await cookies();
  • 2. httpOnly Security 🛡️ ➔ Always pass httpOnly: true in options.
  • 3. Auto Expiry 🕒 ➔ Set maxAge (in seconds) to automatically clean up expired cookies.
