Implementing User Login API in Next.js

Understand how Next.js handles credential validation, checks database user records, and issues HTTP-Only authentication cookies upon successful login.

⚙️

1. User Login Execution Flow

🔑 Credential Validation

1. Handler receives { email, password } via POST request.
2. Searches database: User.findOne({ email }).
3. If user doesn't exist OR password doesn't match ➔ Returns 400 Bad Request ("Invalid Credentials!").

🍪 Cookie Issuance

If credentials match, the handler sets an HTTP-Only cookie:
cookieStore.set("userId", user.id, { httpOnly: true, maxAge: 86400 }).
Subsequent requests automatically send this cookie for authenticated routes!

5. Poora Saar & Golden Master Rule (Hinglish)

💡 User Login Ka Poora Saar:

User Login API ka maksad hota hai user ke Identity Credentials verify karna aur success par browser me Authentication Token / Cookie Set karna.

Handler me User.findOne({ email }) chalate hain. Agar user na mile YA password match na kare, toh 400 Bad Request return karte hain. Correct credentials par cookieStore.set("userId", user.id, { httpOnly: true }) call hota hai. Iske baad browser har standard request ke saath ye cookie automatically attach karke bhejta hai!

🔥 Login Flow Golden Rules:
  • 1. Generic Error Message 🛡️ ➔ "Email not found" ya "Wrong password" mat bolo; always return "Invalid Credentials!".
  • 2. Cookie Persistence 🍪 ➔ Set maxAge so the login stays valid across browser restarts.
  • 3. HTTP 200 OK ✅ ➔ Send 200 status code on successful authentication.
