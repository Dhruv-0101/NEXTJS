1. Next.js API Route Handler Architecture

📥 Request & Database Flow

1. Client submits registration payload ({ name, email, password }) via fetch('/api/register', { method: 'POST' }).
2. Next.js Route Handler invokes await connectDB() to ensure active Mongoose connection.
3. Parses body via await request.json() and executes User.create().

🛡️ Error Code 11000 (Duplicate Index)

MongoDB throws code 11000 when a unique field constraint (e.g. email: { unique: true }) is violated.
The handler catches this error and returns 409 Conflict instead of leaking raw database exceptions!

5. Poora Saar & Golden Master Rule (Hinglish)

💡 User Registration Ka Poora Saar:

User Registration API ek simple 3-step pipeline par kaam karti hai: Read Input ➔ Validate Database Constraints ➔ Return Standard HTTP Status.

Jab user register karta hai, sabse pehle connectDB() MongoDB connection ensure karta hai. Uske baad request.json() payload read karta hai. Agar email pehle se DB me hai, toh MongoDB err.code === 11000 throw karta hai. Is error ko catch karke 409 Conflict response bhejna industry standard hai!

🔥 Registration Golden Formula:
  • 1. HTTP 201 Created ✅ ➔ User successfully create hone par 201 status code bhejein.
  • 2. HTTP 409 Conflict ⚠️ ➔ Duplicate email (err.code === 11000) aane par 409 status code bhejein.
  • 3. HTTP 500 Internal Error 💥 ➔ Unexpected server crash hone par 500 fallback response bhejein.
