Understanding the Request Object in Next.js

Explore what the incoming Request object contains, how to extract URL query parameters, read request headers, and inspect authentication cookies.

Web Standard Request vs NextRequest

Every HTTP method handler receives the incoming request as its first parameter

Next.js Route Handlers mein pehla argument hamesha request hota hai: export function GET(request). Yeh object Node ke traditional req ki tarah nahi hai; yeh modern browser Fetch API Standard Request hai jisme Next.js ke convenience helpers jude hote hain.

app/todos/route.js Logging the Request 
import todos from "../../todos";

export function GET(request) {
  // Inspect the incoming request object in server terminal
  console.log(request);

  return Response.json(todos);
}
Query Parameters (searchParams)

URL se search params read karne ke liye:
const { searchParams } = new URL(request.url);
const query = searchParams.get('filter');
Ya agar NextRequest use karein toh: request.nextUrl.searchParams.get('filter').

Headers & Cookies

Incoming HTTP headers read karne ke liye:
const token = request.headers.get('authorization');
Cookies padhne ke liye:
request.cookies.get('session_id')
