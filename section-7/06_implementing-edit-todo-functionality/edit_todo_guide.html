Implementing Edit Todo Functionality (PUT)

How to modify existing records, update status/text, and enforce backend validation to prevent client-side ID mutation.

Updating a Resource: export async function PUT(request, { params })

Located in app/todos/[id]/route.js

Edit karne ke liye request kisi specific todo par jaati hai (e.g. PUT /todos/1). Backend ko pehle URL parameter se ID milni chahiye, fir body parse karke verify karna hota hai.

app/todos/[id]/route.js PUT Method Implementation 
import { writeFile } from "node:fs/promises";
import todos from "../../../todos";

export async function PUT(request, { params }) {
  const editTodoData = await request.json();
  const { id } = await params;
  
  const todoIndex = todos.findIndex((todo) => id === todo.id);
  const todo = todos[todoIndex];

  // 🛡️ SECURITY GUARD: ID cannot be altered by client
  if (editTodoData.id) {
    return Response.json(
      { error: "Changing ID is not allow." },
      { status: 403 }
    );
  }

  // Merge existing todo with updated fields
  const editedTodo = { ...todo, ...editTodoData };
  todos[todoIndex] = editedTodo;

  await writeFile("todos.json", JSON.stringify(todos, null, 2));
  return Response.json(editedTodo);
}
Why Return 403 Forbidden for ID Changes?

Database ya file store mein Primary Key / ID immutable hoti hai. Agar koi malicious user request body mein { "id": "admin_account", "text": "Hacked" } bhejega, toh application state corrupt ho sakti hai.
Instructor ne isliye explicit check lagaya: if (editTodoData.id) return Response.json({ error: "Changing ID is not allow." }, { status: 403 });.
