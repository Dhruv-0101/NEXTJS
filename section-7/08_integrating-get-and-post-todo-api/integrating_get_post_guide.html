Integrating GET & POST Todo API with Frontend

Connect your React Client Component to your server Route Handlers using fetch('/todos') and synchronize UI state upon adding new items.

From Hardcoded State to Server API

How React interacts with Next.js Route Handlers

Ab tak hamare React component mein hardcoded dummy array tha: const [todos, setTodos] = useState(todosData);.
Chapter 08 mein hum ise live backend se connect karte hain:

app/page.js (Client Component Integration) GET & POST Hookup 
"use client";

import { useEffect, useState } from "react";
import TodoList from "@/components/TodoList";
import TodoForm from "@/components/TodoForm";

export default function Home() {
  const [todos, setTodos] = useState([]);

  // 🟢 Fetch all todos on initial component mount
  useEffect(() => {
    fetchTodos();
  }, []);

  const fetchTodos = async () => {
    const response = await fetch("/todos");
    const todosData = await response.json();
    // Reverse so newest items appear at top
    setTodos(todosData.reverse());
  };

  // 🔵 Add new todo using POST API
  const addTodo = async (text) => {
    const response = await fetch("/todos", {
      method: "POST",
      body: JSON.stringify({ text }),
    });
    const newTodo = await response.json();
    // Prepend newly created todo directly to state
    setTodos([newTodo, ...todos]);
  };

  return (
    /* Todo UI Rendering with TodoForm & TodoList */
  );
}
Relative fetch("/todos")

Kyunki client component aur API route handler dono same domain and port par hain, aapko http://localhost:3000/todos likhne ki zaroorat nahi hai. Bas fetch("/todos") likhiye! Yeh production domain par bhi seamlessly work karega.

Optimistic / Direct State Update

POST request success hone ke baad setTodos([newTodo, ...todos]) karne se poora list dubara fetch karne ki zaroorat nahi padti. Ek hi round-trip mein UI update ho jaati hai!
