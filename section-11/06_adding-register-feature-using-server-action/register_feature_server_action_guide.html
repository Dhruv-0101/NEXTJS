Zod Parse
registerSchema.safeParse(formData) verifies types & rules on Node.js.

Connect DB
await connectDB() initializes or reuses the MongoDB Mongoose connection.
3
Bcrypt Hash

6. Poora Saar & Golden Master Rule (Hinglish)

💡 User Registration Feature Ka Poora Saar:

Production apps me User Registration implementation me 5 interconnected building blocks hote hain:

1. Zod Validation (`safeParse`) ➔ Client par form submitting se pehle checks chalao, aur Server Action me re-validate karo.
2. MongoDB Connection (`connectDB()`) ➔ Direct Server Action ke andar `connectDB()` call karke Mongoose pool reuse karo.
3. Bcrypt Hashing (`bcrypt.hash`) ➔ Never store plain-text passwords! Password ko 10 salt rounds se hash karo (`await bcrypt.hash(password, 10)`).
4. Mongo Duplicate Error (`11000`) ➔ Unique email index error ko `catch (err)` me check karo: `if (err.code === 11000)` return `{ errors: { email: "Email already exists" } }`.
5. Client Navigation (`router.push`) ➔ Client Page me `useEffect` se `state.success` detect karo aur user ko `/login` page par send kar do!

🔥 Full Registration Golden Checklist:
  • 1. Salted Hash Passwords 🛡️ ➔ Hash passwords using `bcrypt.hash(password, 10)` before calling `User.create()`.
  • 2. Handle Code 11000 🏷️ ➔ Explicitly map Mongo error 11000 to user-friendly `{ errors: { email: "Email already exists" } }`.
  • 3. React state Effect Navigation 🚀 ➔ Trigger `router.push('/login')` inside `useEffect` watching `state.success`.
