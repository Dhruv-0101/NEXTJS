Using Server Actions Without Forms

Understand how Server Actions are regular asynchronous RPC functions that can be invoked directly inside button onClick handlers, useEffect hooks, or custom event listeners.

⚙️

1. Form Actions vs. Event-Driven Direct Invocations

📝 Form-Based Binding (<form action={...}>)

Binds action directly to standard HTML <form> submissions.
Receives FormData automatically from inputs.
Supports progressive enhancement (no-JS fallback).

⚡ Event-Driven Direct Call (onClick Handler)

Invokes Server Action as a standard async JavaScript function.
Triggered by any element: <button onClick={handleLogout}>.
Returns a Promise that can be awaited directly!

🔓

2. The `logoutUser()` Action & Direct `onClick` Binding

// app/actions/userActions.js
"use server";

import { cookies } from "next/headers";
import { getUserSessionId } from "@/lib/auth";
import Session from "@/models/sessionModel";

export async function logoutUser() {
  const cookieStore = await cookies();
  const sessionId = await getUserSessionId();
  await Session.findByIdAndDelete(sessionId); // Delete from MongoDB
  cookieStore.delete("sid"); // Delete cookie from browser
  return { success: true };
}
// app/page.js ("use client")
const handleLogout = async () => {
  const response = await logoutUser(); // 👈 Direct async function invocation!
  if (response.success) {
    router.push("/login");
  }
};

return <button onClick={handleLogout}>Logout</button>; // 👈 No <form> element required!

5. Quick Knowledge Check

Q1: Can Server Actions be invoked directly inside an onClick button event handler without a form?

A) Yes! Server Actions are regular async RPC functions and can be awaited inside any event handler.
B) No, Server Actions only work inside <form action="..."> tags.
C) Only if wrapped inside a custom REST API endpoint.
