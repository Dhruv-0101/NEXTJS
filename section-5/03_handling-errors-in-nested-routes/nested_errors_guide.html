Handling Errors in Nested Routes

Understand how errors bubble up through nested route segments and why an error.js file CANNOT catch errors in its own same-level layout.js.

🏗️

1. Next.js App Router Component Tree Architecture

⚙️ JSX Component Nesting Hierarchy

When Next.js compiles route segments, it automatically wraps components in this exact order:
<Layout> ➔ <ErrorBoundary (error.js)> ➔ <Page>

⬆️ Error Propagation (Bubbling Rule)

If a component throws an error, React searches UPWARDS for the nearest parent Error Boundary. Because layout.js wraps error.js at the same folder level, same-level layout errors bubble UP to the parent folder's error.js!

4. Quick Knowledge Check

Q1: Can app/blogs/[blogID]/error.js catch an error thrown in app/blogs/[blogID]/layout.js?

A) Yes, because error.js is in the same folder as layout.js.
B) NO! Because in the component tree, layout.js wraps error.js, so layout errors bubble UP to app/error.js.
C) Yes, if layout.js is marked with "use client".

5. Deep Architectural Summary & Error Propagation Matrix

Use this exact lookup matrix to instantly know where ANY thrown error will land in Next.js App Router:

Where Error is Thrown Same Folder error.js Where Error Lands (Caught By)
app/blogs/[blogID]/page.js ✅ Catches It app/blogs/[blogID]/error.js
app/blogs/[blogID]/layout.js ❌ Bypasses It app/error.js (Parent Level)
app/blogs/page.js ✅ Catches It app/blogs/error.js (or app/error.js)
app/layout.js (Root Layout) ❌ Bypasses app/error.js app/global-error.js (Root Global Boundary)

💡 Key Takeaway to Master Next.js Error Handling (Poora Saar / Golden Rule):

Aapka error.js bas unhi components ka error pakad sakta hai jo uske NEECHE (downstream `{children}` slot ke andar) render hote hain!

Next.js me ek folder ka layout.js apne same-folder ke error.js ko apne andar wrap karta hai. Matlab layout.js UPPAR (Parent) hai aur error.js NEECHE (Child) hai! Isiliye agar layout.js khud phata (error diya), toh neeche baitha error.js use nahi bacha sakta — woh error uchhal kar UPPAR parent folder ke error.js par chala jata hai!

🔥 The 3 Golden Rules (Aapka Quick Cheat Code):
  • 1. 📄 page.js Phata 💥 ➔ Same folder ka error.js bacha lega! ✅
  • 2. 🖼️ Same-folder layout.js Phata 💥 ➔ Same folder ka error.js BYPASS ho jayega! UPPAR wala parent error.js bacha-ega! 🚀
  • 3. 🌐 Root app/layout.js Phata 💥 ➔ app/error.js BYPASS ho jayega! Sirf app/global-error.js bacha sakta hai! 🛡️
