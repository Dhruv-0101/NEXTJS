The 3 Levels of Error Handling in App Router

Next.js provides isolated error boundaries so an error in one section never crashes the entire website:

Level 1: Nested Route

app/blogs/error.js

Catches errors inside /blogs page only! Main layout, header, footer, and other tabs remain fully functional.

Level 2: Root Route

app/error.js

Catches unhandled errors from any page under root. Wrapped inside app/layout.js so root navigation still shows.

Level 3: Root Layout

app/global-error.js

Catches catastrophic errors inside app/layout.js itself! Must define its own <html> and <body> tags.
