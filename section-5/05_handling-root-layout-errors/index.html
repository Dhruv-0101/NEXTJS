Root Layout Errors global-error.js <html> & <body> Required

Handling Root Layout Errors with global-error.js

Understand why app/error.js cannot catch errors in app/layout.js, and how global-error.js serves as the ultimate fallback for your entire application.

⚙️

1. Why app/error.js Fails for Root Layout Errors

❌ app/error.js Sits INSIDE Root Layout

In Next.js component nesting: <RootLayout> ➔ <app/error.js> ➔ <Page>.
Because app/layout.js wraps app/error.js, if app/layout.js throws an error, app/error.js is BYPASSED!

🔮 global-error.js Replaces Entire Document

When app/layout.js fails, the root <html> and <body> tags are completely destroyed!
global-error.js MUST explicitly define its own <html> and <body> tags.

3. Code Breakdown: Lesson Files

app/layout.js (Root Layout throwing 50% random error)
export default function RootLayout({ children }) { const randomNumber = Math.random(); // 🎲 50% Random Error in Root Layout: if (randomNumber > 0.5) { throw new Error("Error occurred in Root Layout"); } return ( <html lang="en" className="dark"> <body> <Header /> {children} </body> </html> ); }
app/global-error.js (Root Layout Error Fallback)
"use client"; export default function GlobalError({ error, reset }) { return ( <html lang="en" className="dark"> // 👈 MANDATORY: Must define html & body! <body> <div> <h2>Something went wrong in root layout</h2> <button onClick={() => window.location.reload()}>Try Again</button> </div> </body> </html> ); }
app/error.js (Page Level Error Boundary)
"use client"; export default function Error({ error, reset }) { // Catches errors in app/page.js, but NOT app/layout.js! return <div>Something went wrong in home page</div>; }

5. Poora Saar & Golden Master Rule (Hinglish)

💡 Root Layout Errors Ka Poora Saar:

Next.js App Router me app/layout.js sabse top level (Root Layout) hota hai. Uske ANDAR app/error.js aur app/page.js baithte hain.

Agar app/layout.js (Root Layout) phat jaye (error de de), toh app/error.js usko **NAHI bacha sakta**, kyunki `app/error.js` khud layout ke andar rehta hai! Jab Root Layout phatta hai, toh poore document ke <html> aur <body> tags tabah (destroy) ho jaate hain. Iske liye Next.js ne special app/global-error.js diya hai, jo poore HTML page ko replace karta hai aur jisme <html> & <body> likhna **MANDATORY** hota hai!

🔥 The Ultimate Root Error Formula:
  • 1. 📄 app/page.js Phata 💥 ➔ app/error.js bacha lega! Root Layout intact rahega. ✅
  • 2. 🌐 app/layout.js (Root Layout) Phata 💥 ➔ app/error.js BYPASS ho jayega! Sirf app/global-error.js bacha sakta hai! 🛡️
  • 3. 🏷️ Mandatory Tags in global-error.js ⚠️ ➔ <html> aur <body> tags likhna FARZ (Mandatory) hai!
