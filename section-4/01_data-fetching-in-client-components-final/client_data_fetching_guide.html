01. Data Fetching in Client Components

Understanding Client-Side Data Fetching, why View Page Source gives empty HTML, and why it hurts SEO & initial performance.

Project Code: app/posts/page.js

In this lesson, we fetch a list of 5 blog posts from JSONPlaceholder inside a Client Component using standard React hooks.

"use client"; // server se blank html file aayi hogi. sab kuch client show kiya hai api se. (CSR) // agar view page source karega to kuch nahi sirf empty html page aayega! import { useEffect, useState } from "react"; const Posts = () => { const [posts, setPosts] = useState([]); useEffect(() => { async function fetchPosts() { const response = await fetch( "https://jsonplaceholder.typicode.com/posts?_limit=5" ); const data = await response.json(); setPosts(data); } fetchPosts(); }, []); return ( <> <h1>Posts</h1> <div className="posts-container"> {posts.map(({ id, title, body }) => ( <div className="post-card" key={id}> <h2>{title}</h2> <p>{body}</p> </div> ))} </div> </> ); }; export default Posts;

Mental Model & Real-World Analogy

Restaurant Analogy: DIY Recipe Kit

Client Data Fetching ka matlab hai: Server aapko bana-banaya khana dene ke bajay ek khali plate (Blank HTML) aur kachha samaan + recipe card (JS bundle) bhejta hai.

Customer (Browser) pehle recipe padhta hai (JS execute karta hai), phir market se sabji mangwata hai (API call karta hai), aur finally khud khana pakata hai (DOM render). Isme time lagta hai!

"View Page Source" vs "Inspect Element"

<!-- View Page Source: Exactly what server sent --> <div id="__next"> <h1>Posts</h1> <div class="posts-container"></div> <!-- EMPTY! No posts inside --> </div>

When to Use vs When to Avoid Client Fetching

Advantages Disadvantages
✅ Great for user-specific private data (e.g. User Profile, Notifications after login). ❌ Weak SEO: Search engine crawler gets empty HTML.
✅ Perfect for real-time polling or search auto-suggest as user types. ❌ Slow Initial Render: Waterfall of HTML → JS → API → Render.
✅ Familiar React pattern (`useState` + `useEffect`). ❌ Exposes API details: Endpoint URLs and client tokens are visible in Network tab.
