02. Data Fetching in Server Components

How async / await inside Server Components eliminates useEffect, enables direct database calls, and generates 100% SEO-ready HTML.

Project Code: app/todos/page.js

Notice how simple and clean this code is compared to traditional React! No useState, no useEffect, and no loading flag boolean states.

// By default, all components inside the `app` directory are SERVER COMPONENTS const Posts = async () => { // Direct fetch right inside the component function body! const response = await fetch( "https://jsonplaceholder.typicode.com/todos?_limit=5" ); const todos = await response.json(); return ( <> <h1>Todos</h1> <div className="todos-container"> {todos.map(({ id, title, completed }) => ( <div className="todo-item" key={id}> <input type="checkbox" checked={completed} readOnly /> <p>{title}</p> </div> ))} </div> </> ); }; export default Posts;

Mental Model & Real-World Analogy

Kitchen Chef Analogy

Yahan Server ek Master Chef hai. Jab customer (browser) page mangta hai, Chef pehle kitchen me database/API se saara masala aur data nikalta hai, pura khana (HTML) taiyaar karta hai, aur customer ke table par ready-to-eat plate rakh deta hai!

Customer ko kachhi sabji ya recipe (JS code) download karne ki zarurat nahi padti. Page khulte hi data screen par hota hai!

Zero Leakage & Security

Kyunki fetch call server par execute hoti hai, aap yahan bina dare Database Password, Secret API Keys, ya Private Tokens use kar sakte ho.

Browser ke Network tab me sirf page ka HTML aayega, aapki backend API keys browser me 1% bhi expose nahi hoti!

Direct Comparison: Client Fetch vs Server Fetch

01. Client Component

  • ❌ Needs "use client" directive
  • ❌ Requires useState & useEffect boilerplates
  • ❌ Blank initial HTML (No SEO benefit)
  • ❌ JavaScript bundle downloaded by user's browser
  • ❌ API credentials visible in Browser DevTools Network tab

02. Server Component (RSC)

  • ✅ No directive needed (Default in App Router)
  • ✅ Direct async / await (Clean, minimal code)
  • ✅ 100% Pre-rendered HTML (Perfect SEO for Google)
  • ✅ 0 KB JS bundle sent to client for data fetching
  • ✅ Safe to access database, environment secrets, and backend files
