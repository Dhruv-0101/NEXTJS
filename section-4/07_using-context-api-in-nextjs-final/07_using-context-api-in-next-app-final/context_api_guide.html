07. Using Context API in Next.js App Router

How to provide global state (like Theme, Auth, Cart) using React Context without accidentally turning your entire Server-Rendered App into Client Components!

The Core Next.js Dilemma

Server Components Context API Support Nahi Karte!

createContext aur useContext React ke client-side hooks hain jo state aur re-rendering par depend karte hain. Next.js ke Server Components me Context direct create ya consume nahi ho sakta.

Dilemma: Agar hum global state ke liye app/layout.js par "use client" laga dein, toh hamari poori application (har page aur har component) Client Component ban jayegi aur Server Components ke saare fayde khatam ho jayenge!

The Golden Solution: The "Children" Provider Pattern

1. Provider ko ek separate file me banao aur wahan "use client" lagao: context/ThemeContext.js.
2. Provider ko {children} accept karne do.
3. app/layout.js ko **Server Component hi rehne do**, aur usme <ThemeProvider>{children}</ThemeProvider> wrap karo!
Kamaal ki baat: Kyunki {children} ko Server Component (layout) ne as prop pass kiya hai, isliye saare children Server Components hi rehte hain!

Project Code Implementation

1. context/ThemeContext.js ("use client")

"use client"; import { createContext, useContext, useEffect, useState } from "react"; const ThemeContext = createContext(); export function useTheme() { return useContext(ThemeContext); } export default function ThemeProvider({ children }) { const [isDark, setIsDark] = useState(true); function toggleTheme() { setIsDark((prev) => !prev); } useEffect(() => { const saved = localStorage.getItem("isDark") === "true"; setIsDark(saved); }, []); useEffect(() => { localStorage.setItem("isDark", isDark); if (isDark) { document.documentElement.classList.add("dark"); } else { document.documentElement.classList.remove("dark"); } }, [isDark]); return ( <ThemeContext.Provider value={{ isDark, toggleTheme }}> {children} </ThemeContext.Provider> ); }

2. app/layout.js (Server Component!)

// Notice: NO "use client" here! // RootLayout remains a 100% Server Component import "./globals.css"; import ThemeProvider from "@/context/ThemeContext"; export default function RootLayout({ children }) { return ( <html lang="en" className="dark"> <body> {/* Client Provider wraps Server Children */} <ThemeProvider> {children} </ThemeProvider> </body> </html> ); }
Consuming Context in Components:

Header ya Buttons me bas const { isDark, toggleTheme } = useTheme(); call karo (un components me "use client" hona chahiye).
