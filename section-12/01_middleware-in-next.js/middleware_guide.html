Understanding Middleware in Next.js

Master Edge Middleware in Next.js: intercept incoming HTTP requests before page rendering to enforce authentication rules, inspect cookies, and trigger instant server redirects.

⚙️

1. Request Interception Pipeline

1
Incoming Request
Browser requests a URL (e.g. /, /login, /register).
2
Matcher Filter
Next.js checks config.matcher. If URL matches, request routes to Edge Middleware.
3
Cookie & Path Check
middleware(request) reads request.cookies.get("sid") and pathname.
4
Redirect or Pass
Executes Response.redirect() instantly OR allows request to reach page render!
🛡️

2. Route Protection Logic & `config.matcher` Filter

// middleware.js
export const middleware = (request) => {
  const hasSession = request.cookies.get("sid");
  const { pathname, origin } = request.nextUrl;

  if (hasSession) {
    if (pathname === "/login" || pathname === "/register") {
      return Response.redirect(new URL("/", origin)); // 🔒 Logged in user cannot visit login!
    }
  } else if (pathname === "/") {
    return Response.redirect(new URL("/login", origin)); // 🛑 Unauthenticated user redirected!
  }
};

export const config = {
  matcher: ["/", "/login", "/register"], // 👈 Limits execution to these routes only!
};

6. Poora Saar & Golden Master Rule (Hinglish)

💡 Next.js Middleware Ka Poora Saar:

Next.js Middleware (`middleware.js`) root directory me rehne wali ek aisi special file hai jo har incoming HTTP request ke beech me **Security Gatekeeper** ki tarah khadi hoti hai.

1. Edge Execution (Zero UI Flash) ⚡ ➔ Request Browser se nikalte hi sabse pehle Edge Network par `middleware.js` chalta hai (Page rendering hone se pehle). Agar user authenticated nahi hai, toh page HTML render hone se PEHLE hi direct `/login` redirect ho jata hai (bilkul bhi screen glitch nahi aata!).
2. Cookie Inspection 🍪 ➔ `request.cookies.get("sid")` se direct browser session cookies read kar sakte hain.
3. Matcher Filter (`config.matcher`) 🎯 ➔ Humesha `matcher: ["/", "/login", "/register"]` export karo taaki middleware static images (`.png`), CSS, ya JS chunks par fizool me na chale.

🔥 Middleware Golden Rules:
  • 1. Name & Location 📁 ➔ File name must be strictly `middleware.js` in root or `src/` directory.
  • 2. Always Export Matcher 🎯 ➔ Define `export const config = { matcher: [...] }` to prevent running on static assets.
  • 3. Edge Redirects 🚀 ➔ Use `Response.redirect(new URL("/path", request.nextUrl.origin))` for clean server-side redirects.
