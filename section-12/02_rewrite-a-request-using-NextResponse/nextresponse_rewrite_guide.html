NextResponse.rewrite() Masked URL Proxy Unchanged Address Bar

Rewriting Requests using NextResponse.rewrite()

Learn how NextResponse.rewrite() serves target page content under the hood while preserving the user's requested URL path in the browser address bar.

⚙️

1. Redirect vs. Rewrite Comparison

🔄 NextResponse.redirect()

• Browser URL Bar: CHANGES! (e.g. /home ➔ /)
• HTTP Status Code: 307 Temporary / 308 Permanent Redirect.
• Use Cases: Auth logins, access denial, domain moves.

🎭 NextResponse.rewrite()

• Browser URL Bar: STAYS SAME! (Remains /home)
• HTTP Status Code: 200 OK.
• Use Cases: Masked URL aliases, A/B testing, feature flags, legacy path mapping.

📜

2. `middleware.js` Implementation Pattern

import { NextResponse } from "next/server";

export const middleware = (request) => {
  // 🎭 Serves content of "/" while browser URL bar remains "/home":
  return NextResponse.rewrite(new URL("/", request.nextUrl.origin));
};

export const config = {
  matcher: ["/home"], // 👈 Only triggers when visiting /home
};

6. Poora Saar & Golden Master Rule (Hinglish)

💡 NextResponse.rewrite() Ka Poora Saar:

Next.js Middleware me Redirect aur Rewrite ke beech ka farq samajhna sabse important concept hai!

1. Redirect (`NextResponse.redirect`) 🔄 ➔ Browser address bar me URL Badal jata hai (e.g. `/home` ➔ `/`). HTTP Status Code 307 hota hai. Use case: Login protection.
2. Rewrite (`NextResponse.rewrite`) 🎭 ➔ Browser address bar me URL Bilkul NAHI badalta (STAYS `/home`), lekin under the hood Next.js `http://myapp.com/` (Home Page) ka content fetch karke screen par dikha deta hai! HTTP Status Code 200 OK hota hai.
3. Use Cases 🎯 ➔ Multi-tenant subdomains, custom URL alias, A/B testing, legacy path rewriting.

🔥 Redirect vs Rewrite Rules:
  • 1. URL Bar Behavior 🎭 ➔ `rewrite()` preserves original requested URL in address bar; `redirect()` changes it.
  • 2. Internal Proxy ⚙️ ➔ `rewrite()` acts as an internal reverse proxy at Edge layer.
  • 3. HTTP 200 vs 307 📊 ➔ `rewrite()` returns 200 OK; `redirect()` returns 307 Temporary Redirect.
