Using ESLint as a Code Formatter

Understand how ESLint can enforce code style rules (quotes, semicolons, indentation) and automatically format your codebase on save using VS Code integration.

⚙️

1. Linting (Code Quality) vs. Formatting (Code Style)

🔍 Code Quality (Linting)

• Focus: Logic bugs, undefined variables, broken React hooks dependencies.
• Examples: no-unused-vars, react-hooks/exhaustive-deps.
• Fix: Often requires developer decision & refactoring.

🎨 Code Style (Formatting)

• Focus: Visual layout, quotes consistency, semicolons, 2-space indentation.
• Examples: semi, quotes, indent, comma-dangle.
• Fix: 100% auto-fixable via --fix or Save!

📜

2. Configuring Formatting Rules & VS Code Auto-Save

// eslint.config.mjs
const eslintConfig = [
  ...compat.config({
    extends: ["next/core-web-vitals", "next/typescript"],
    rules: {
      semi: ["error", "always"], // 👈 Mandatory semicolons
      quotes: ["error", "single"], // 👈 Enforce single quotes
      indent: ["error", 2], // 👈 2 spaces indent
    }
  })
];
// .vscode/settings.json (Auto-Fix on Save)
{
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": "always" // 👈 Automatically format on Ctrl+S / Cmd+S!
  }
}

6. Poora Saar & Golden Master Rule (Hinglish)

💡 Using ESLint as a Formatter Ka Poora Saar:

ESLint na sirf code ke bugs dhundta hai, balki code ko Auto-Format karke pooray team ke code style ko uniform bhi rakhta hai!

1. Formatting Rules 🎨 ➔ `eslint.config.mjs` me `semi: ['error', 'always']`, `quotes: ['error', 'single']`, `indent: ['error', 2]` rules add karke code style enforce kiya jata hai.
2. Auto-Fix on Save (`.vscode/settings.json`) ⚡ ➔ `"editor.codeActionsOnSave": { "source.fixAll.eslint": "always" }` add karne par jaise hi developer `Ctrl + S` dabata hai, VS Code automatic sabhi quotes, spaces aur semicolons ko format kar deta hai!
3. CLI Auto-Fix (`npx eslint . --fix`) 🚀 ➔ Terminal command se poore project ki formatting ek click me fix ho jaati hai!

🔥 Formatter Golden Rules:
  • 1. Auto-Fix on Save ⚡ ➔ Always configure `source.fixAll.eslint: always` in `.vscode/settings.json`.
  • 2. Single Quote & Semi Rules 🎨 ➔ Set explicit formatting rules in `eslint.config.mjs`.
  • 3. CLI --fix Flag 🚀 ➔ Run `npx eslint . --fix` before committing code to format the entire codebase.
