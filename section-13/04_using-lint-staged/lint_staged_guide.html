Using lint-staged for Fast Selective Linting

Understand how lint-staged filters Git status to execute ESLint and Prettier strictly on staged files (git add), boosting linter performance by 100x.

⚙️

1. Full-Project Scans vs. Staged-Only Scans

🐢 Full Project Scan (next lint)

• Scans 5,000+ project files on every commit.
• High execution time (~30s - 60s delay).
• Frustrates developers during rapid commits.

⚡ lint-staged (Selective Scan)

• Inspects Git status and scans ONLY staged files (git add).
• Blazing fast execution (<1 second delay for 2 modified files).
• Auto-fixes and re-stages files before commit completes!

📜

2. Next.js `.lintstagedrc.js` Configuration Pattern

const path = require('path');

// Formats file array into: next lint --fix --file app/page.js --file lib/auth.js
const buildEslintCommand = (filenames) =>
  `next lint --fix --file ${filenames
    .map((f) => path.relative(process.cwd(), f))
    .join(' --file ')}`;

const buildPrettierCommand = (filenames) =>
  `prettier --write ${filenames.join(' ')}`;

module.exports = {
  '*.{js,jsx,ts,tsx}': [buildEslintCommand, buildPrettierCommand],
  '*.{json,css,scss,md}': [buildPrettierCommand],
};

6. Poora Saar & Golden Master Rule (Hinglish)

💡 Using lint-staged Ka Poora Saar:

Production apps me pooray project (5,000+ files) par `next lint` chalamne se commit process bohot slow (~45 seconds) ho jaati hai. `lint-staged` iss problem ka ultimate solution hai!

1. Selective Staged Scanning ⚡ ➔ `lint-staged` Git status ko inspect karta hai aur **SIRF UNHI FILES** par ESLint aur Prettier chalata hai jinhe aapne `git add` se stage kiya hai (Execution time: <1 second!).
2. Next.js Relative Path Command (`.lintstagedrc.js`) ⚙️ ➔ Next.js ke `next lint --file` argument ke liye custom helper function `buildEslintCommand` use kiya jata hai jo file paths ko relative format me pass karta hai.
3. Auto-Fix & Auto Re-Stage 🔄 ➔ Linting ke dauran auto-fixed formatting changes automatically re-stage ho jaati hain bina developer ke extra manual steps ke!

🔥 lint-staged Master Rules:
  • 1. Config File 📁 ➔ Use `.lintstagedrc.js` in root directory for Next.js path helpers.
  • 2. Match File Extensions 🎯 ➔ Group `*.{js,jsx,ts,tsx}` for ESLint + Prettier, and `*.{json,css,md}` for Prettier only.
  • 3. Sub-Second Commits ⚡ ➔ Keeps Git commit pipeline lightning fast while maintaining 100% code quality.
