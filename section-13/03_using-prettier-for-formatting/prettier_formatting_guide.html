Using Prettier for Code Formatting in Next.js

Learn how to integrate Prettier alongside ESLint to handle 100% of code formatting, auto-formatting on save, and automatically sorting Tailwind CSS classes.

⚙️

1. The ESLint + Prettier Division of Responsibility

🔍 ESLint (Code Quality & Linter)

• Catches logic bugs & type errors.
• Enforces React hooks rules & unused variables.
• Formatting rules turned OFF via eslint-config-prettier!

🎨 Prettier (Code Formatter)

• Formats indentation, quotes, semicolons, line breaks.
• Automatically sorts Tailwind CSS class names.
• Executes instantly on save (formatOnSave: true).

📜

2. Prettier & ESLint Configuration Files

// .prettierrc
{
  "singleQuote": true,
  "semi": false,
  "tabWidth": 2,
  "plugins": ["prettier-plugin-tailwindcss"] // 👈 Auto-sorts Tailwind classes!
}
// eslint.config.mjs (Disables conflicting ESLint formatting rules)
const eslintConfig = [
  ...compat.config({
    extends: ["next/core-web-vitals", "next/typescript", "prettier"], // 👈 Disables conflicts!
  }),
];

6. Poora Saar & Golden Master Rule (Hinglish)

💡 Using Prettier with ESLint Ka Poora Saar:

Production apps me ESLint + Prettier ka combination sabse powerful code quality setup mana jata hai!

1. Division of Work 🤝 ➔ ESLint code ke bugs (unused variables, hooks dependencies) dhundta hai, jabki Prettier 100% code layout aur formatting sambhalta hai.
2. Conflict Resolution (`eslint-config-prettier`) 🛡️ ➔ ESLint me formatting rules (semi, quotes) ko OFF karne ke liye `eslint.config.mjs` me `extends: [..., "prettier"]` extend karna compulsory hai.
3. Tailwind CSS Auto-Sorting (`prettier-plugin-tailwindcss`) 🎨 ➔ `.prettierrc` me `"plugins": ["prettier-plugin-tailwindcss"]` daalne se aapke Tailwind classes (e.g. `className="p-4 flex items-center..."`) automatically standardized order me sort ho jaate hain!

🔥 Prettier Master Rules:
  • 1. Extend "prettier" in ESLint 🛡️ ➔ Always extend `"prettier"` last in `eslint.config.mjs` to disable rule conflicts.
  • 2. Add Tailwind Plugin 🎨 ➔ Use `prettier-plugin-tailwindcss` to auto-sort utility classes on save.
  • 3. Default Formatter ⚡ ➔ Set `"editor.defaultFormatter": "esbenp.prettier-vscode"` and `"editor.formatOnSave": true`.
