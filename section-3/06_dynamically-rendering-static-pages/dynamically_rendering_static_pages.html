Dynamically Rendering Static Pages in Next.js

Learn how to force static pages or routes to render dynamically on every user HTTP request using Route Segment Configs and Dynamic API Triggers.

🧠 Hinglish Summary:
By default Next.js saare simple pages ko static bana deta hai. Lekin agar kisi static page par export const dynamic = 'force-dynamic', cookies(), headers(), searchParams, ya revalidate = 0 lagayein, toh Next.js us page ko Dynamic Rendering me convert kar deta hai — yaani har user visit par Node.js server code dobara execute hota hai!

5 Ways to Force Dynamic Rendering

Methods to switch static pre-rendered routes into request-time dynamic rendering.

1. `export const dynamic = 'force-dynamic'`

Explicit Route Segment Config. Forces Next.js to bypass static caching and render the component on every request.

2. `export const revalidate = 0`

Disables static revalidation caching completely. Forces dynamic fetch on every request.

3. Reading `cookies()` or `headers()`

Calling cookies() or headers() from next/headers inside a Server Component automatically opts the route into Dynamic Rendering.

4. Reading `searchParams`

Accessing URL query parameters (e.g. /blogs?page=2) in page props switches the component to dynamic rendering.

5. Uncached `fetch()` Request

Using fetch(URL, { cache: 'no-store' }) prevents static caching and forces dynamic execution.

Route Segment Config Options

All valid values for `export const dynamic` in Next.js App Router.

Segment Config Option Behavior & Rendering Mode Use Case
export const dynamic = 'auto' Default option. Pre-renders statically if no dynamic functions are used. Standard Next.js pages.
export const dynamic = 'force-dynamic' Forces Dynamic Rendering. Re-executes server component on every user HTTP request. Real-time live feeds, user dashboards, shopping cart checkout.
export const dynamic = 'error' Forces static rendering, and throws an error if any dynamic function is used. Strict static landing pages.
export const dynamic = 'force-static' Forces static rendering and overrides any dynamic functions to return empty/default values. Static documentation, offline caching.
