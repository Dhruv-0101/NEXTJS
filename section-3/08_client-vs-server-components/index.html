Server Components vs Client Components in Next.js

Learn how Next.js App Router defaults to React Server Components (RSC) for 0KB JavaScript bundle sizes, and when to opt into Client Components using "use client".

🧠 Hinglish Summary:
Next.js App Router me saare components by default Server Components hote hain. Iska sabse bada fayda ye hai ki inka JS code browser par kabhi bhej nahi jata (0 KB bundle size!). Jab aapko React hooks (`useState`, `useEffect`), event handlers (`onClick`), ya browser APIs (`window`, `localStorage`) ki zarurat padti hai, tabhi aap file ke top par "use client"; likhte hain!

Server Components (Default)

Executes ONLY on the server. The component code is rendered into HTML/RSC payload and NEVER sent to the client browser bundle.

  • Bundle Impact: 0 KB JavaScript sent to browser.
  • Direct Access: Databases, secret API keys, filesystem (`fs`).
  • Async Capability: Can be declared as async function MyComp().
  • No React Hooks: Cannot use `useState`, `useEffect`, `useRef`.
  • No Event Listeners: Cannot attach `onClick`, `onChange`.
  • No Browser APIs: Cannot access `window` or `localStorage`.

Client Components (`"use client"`)

Pre-rendered on the server into HTML, then hydrated on the client where its JS bundle executes to enable interactivity.

  • React Hooks: Fully supports `useState`, `useEffect`, `useContext`.
  • Interactivity: Attach `onClick`, `onChange`, `onSubmit` handlers.
  • Browser APIs: Access `window`, `localStorage`, `document`.
  • Bundle Impact: JavaScript IS included in browser download bundle.
  • No Secrets: Cannot contain server DB secrets or private keys.
  • No Async Components: Cannot be `async function MyComp()`.

💡 Crucial Best Practice: Don't Put `"use client"` at the Page Level!

"Agar aap poore page.js par "use client"; likh doge, toh page ke andar jitne bhi child components import honge, unka poora code CLIENT bundle me chala jayega!"

✅ Solution: Move Client Components down to the Leaf Nodes!

Main page app/blogs/page.js ko **Server Component (Default)** hi rehne do.
Aur jahan aapko onClick button ya useState ki zarurat ho (jaise Button.js ya Likes.js), sirf **un chhote separate files me `"use client";` lagao** aur parent Server Component me import karo!

Project Code Case Study

Examining components/Button.js, components/Likes.js & app/blogs/page.js

🟢 Client Component: components/Button.js

"use client"; export default function Button() { return ( <button onClick={() => { console.log("Button Clicked"); }} > Click Me </button> ); }

🔵 Server Component: components/Views.js

// No "use client" -> Defaults to Server Component export default async function Views() { // 🟢 Runs ONLY on Node.js Server! 0KB JS sent to browser. console.log("Views Component"); return <div>10k Views</div>; }

Exact Line-by-Line Breakdown

Detailed analysis of components/Button.js, Likes.js, and Views.js

File: components/Button.js

Client Component Directive
L1
"use client";
CLIENT DIRECTIVE
Tells Next.js compiler that this component and its imports belong to the Client Boundary. Its JS bundle will be sent to the browser for hydration.
L6-8
onClick={() => { console.log("Button Clicked"); }}
Interactive Event Listener: Can only be attached in Client Components. When the user clicks the button in their browser, "Button Clicked" logs inside the Browser DevTools Console (F12).

File: components/Likes.js

Server Component Notes & State
L1-5
// window & localstorage server pe kam nahi karta
Handwritten PDF Notes Analysis:
• Server components run on Node.js, so global objects like window or localStorage do not exist on the server.
• Attempting to access window without "use client" throws ReferenceError: window is not defined.
L18
const [likes, setLikes] = useState(0);
React State Hook: React hooks like useState can ONLY be used inside Client Components marked with "use client".

Master Feature Comparison Matrix

Quick lookup table for Server Components vs Client Components capability.

Feature / Capability Server Component (Default) Client Component (`"use client"`)
Execution Environment Server ONLY (Node.js) Server (SSR HTML) + Client (Browser Hydration)
JS Bundle Size 0 KB (Excluded from bundle) Included in browser JS download bundle
React Hooks (`useState`, `useEffect`) ❌ Not Allowed ✅ Full Support
Event Listeners (`onClick`, `onChange`) ❌ Not Allowed ✅ Full Support
Browser APIs (`window`, `localStorage`) ❌ Throws `ReferenceError` ✅ Full Support
Direct DB Queries & Server Secrets ✅ Safe & Secure ❌ Security Risk (Exposed to client)
Async Component (`async function`) ✅ Supported ❌ Not Supported in Client Components
