Static Site Generation (SSG) in Next.js App Router

Learn how export async function generateStaticParams() transforms dynamic route segments (like app/blogs/[blogID]/page.js) into pre-compiled Static HTML Pages at Build Time!

🧠 Hinglish Summary:
Next.js App Router me generateStaticParams() ka kaam dynamic routes (jaise [blogID]) ke saare IDs ko build time (`next build`) par fetch karke pehle se static HTML files bana lena hota hai. Production me jab user kisi link pe click karta hai, toh server code re-run nahi hota, direct pre-rendered HTML CDN se milti hai!

How `generateStaticParams()` Works

Converting request-time dynamic routes into build-time pre-rendered static pages.

⚡ Without `generateStaticParams()` (Dynamic Route)

Route is classified as ƒ Dynamic.

  • Build step creates ZERO blog HTML files.
  • Every user request executes Blog() component on Node.js server.
  • Server CPU load & database queries on every visit.

🚀 With `generateStaticParams()` (SSG Route)

Route is classified as ● SSG (Prerendered Static).

  • Next.js fetches API data at next build phase.
  • Generates /blogs/1.html, /blogs/2.html ... static files.
  • User visits get instant 0ms CDN responses!

Project Code Case Study

Examining app/blogs/[blogID]/page.js in project 03_static-site-generation-in-next.js

📄 File: app/blogs/[blogID]/page.js

import Link from "next/link"; // 🟣 Export special function to tell Next.js which paths to pre-render at build time export async function generateStaticParams() { const response = await fetch("https://jsonplaceholder.typicode.com/todos"); const data = await response.json(); return data.map(({ id }) => ({ blogID: `${id}` })); } const Blog = async ({ params }) => { const { blogID } = await params; console.log("blogID: ", blogID); return ( <div> <h1>Welcome to Our Blog {blogID}</h1> <p>This is blog {blogID} page.</p> </div> ); }; export default Blog;

Dynamic Fallback Modes (`dynamicParams`)

What happens when a user visits a dynamic route ID that was NOT returned by generateStaticParams()?

1. `export const dynamicParams = true` (Default)

If a user requests an un-generated path (e.g. /blogs/999):
• Next.js renders the page On-Demand dynamically on the server for the first user.
• It saves/caches the resulting HTML statically so future users get 0ms CDN responses!

2. `export const dynamicParams = false`

Strict mode: If a path was NOT included in generateStaticParams():
• Next.js immediately returns a 404 Not Found page without rendering on-demand.
