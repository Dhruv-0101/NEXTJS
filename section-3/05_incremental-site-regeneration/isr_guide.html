Incremental Static Regeneration (ISR) in Next.js

Learn how ISR allows you to update static pages in the background without rebuilding your entire website, using the Stale-While-Revalidate caching strategy!

🧠 Hinglish Summary:
ISR ka sabse bada fayda ye hai ki aap dynamic content walo pages ko Static HTML ki speed (0ms CDN latency) ke saath serve kar sakte ho, aur saath hi background me revalidate: 5 time beetne par purana content silently update ho jata hai. User ko screen par instantly old cached page milta hai aur aane wale next user ko naya updated page mil jata hai!

Special Clarification: User C aur User D ke beech Time Math Explained!

"User C (10:00:07) aur User D (10:00:12) ke beech 5 sec beet gaye. Toh kya User D visit par naya background regeneration trigger hoga?"

🔑 Crucial Rule: Next.js 5 seconds kis time se count karta hai?

Next.js 5 seconds ka timer pichle User (User C ke visit time `10:00:07`) se count NAHI karta!
Balki 5 seconds ka timer pichli REGENERATION TIMESTAMP (`10:00:06`) se count hota hai!

• Pichli Regeneration Time: 10:00:06
• Revalidate Limit: 5 seconds
• Cache Expiry Time: 10:00:06 + 5s = 10:00:11

User C Visit (`10:00:07`):

• Time since last regeneration (`10:00:06`): 1 second.
• 1s < 5s ➔ Cache is 100% FRESH!
• User C receives NEW HTML `10:00:06`. No background build.

User D Visit (`10:00:12`):

• Time since last regeneration (`10:00:06`): 6 seconds.
• 6s > 5s limit ➔ Cache is now STALE!
• User D gets HTML `10:00:06` instantly ➔ AND triggers a NEW background regeneration for `10:00:12`!

💡 Ek Line Me Samjho (The Golden Rule of ISR)

Next.js har 5 second me automatically background me cron runner nahi chalata! Balki jab **koi user page request maangta hai** aur pichli regeneration se 5 sec beet gaye hote hain, tab background me naya version banta hai, aur next user ko wahi updated HTML milta hai!

import Link from "next/link"; export const dynamicParams = false; // export const revalidate = 5; // Option A: Route Segment Level ISR export async function generateStaticParams() { const response = await fetch("https://jsonplaceholder.typicode.com/todos"); const data = await response.json(); return data.map(({ id }) => ({ blogID: `${id}` })); } const Blog = async ({ params }) => { const { blogID } = await params; // Option B: Fetch Level ISR (Revalidates fetch data every 5 seconds) const response = await fetch("https://jsonplaceholder.typicode.com/todos/1", { next: { revalidate: 5 }, }); const data = await response.json(); return ( <div> <h1>Welcome to Our Blog {blogID}</h1> <h2>Date: {new Date().toLocaleString()}</h2> <p>This is blog {blogID} page.</p> </div> ); }; export default Blog;
